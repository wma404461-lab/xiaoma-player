小马播放器+录屏 0.6.18

1. 打开小马播放器+录屏.exe，点击顶部“录屏”。
2. 在面板顶部选择保存位置，点击“框选区域”，拖出要录制的范围。
3. 点击“开始录制”，立即开始，没有倒计时。默认保持屏幕原始清晰度、60 帧、电脑声音。
4. 在浮动控制条点击“结束”，保存后播放器自动打开刚录好的录像。点击“直接剪辑”旁的“查看路径”，可以打开录像所在文件夹并选中录像。
5. 点击“直接剪辑”，在播放进度条上拖动两端白边，保留中间需要的部分，然后点击“保存片段”。片段自动保存到原视频文件夹，命名为“原文件名_剪辑.mp4”，同名时加编号。新片段紧接原片加入播放列表，原片和其他条目保留。

绿色边框提示已选择的录制范围；结束录制后保留。点击退出、关闭录屏面板或退出播放器时，边框和控制条一起消失。提示框不会进入录像。
重新选择范围：点击“重新框选”。支持跨越多个显示器选择一个连续区域。
录自己的声音：勾选“我的声音”。
暂停：浮动控制条点击“暂停”，继续时点击“继续”。

快捷键：Ctrl+Alt+R 开始/结束；Ctrl+Alt+P 暂停/继续。
录像默认在“视频\小马录屏”。保存位置放在录屏面板顶部，可以直接选择或打开文件夹。
原始清晰度、4K、1080p、30/60 帧、自动结束和声音设备放在“更多设置”。
打开任何视频后也可点击播放操作栏的“剪辑”，拖动两端白边后保存片段。“查看路径”会定位当前视频。

录屏结束后，点击右下角“检查更新”即可获取后续版本。更新保留设置和录像。
正常关闭播放器会先保存正在录制的视频；保存期间请等待，不要强制结束进程。

输出 4K 不会增加低分辨率屏幕的原始细节。流畅度取决于当前负载、驱动和存储，录制报告位于录像文件夹的“录制报告”内。
原录制组件启动失败时会自动切换兼容录制，使用 GDI 区域采集、WASAPI 声音和可用的显卡编码器。兼容录制在重负载下可能补齐重复帧以维持音画同步，报告会记录重复帧数量。

性能优化：打开录屏面板时后台准备录制组件与可用显卡编码器；兼容采集使用独立线程、高分辨率定时器与固定帧缓冲。已采集画面按顺序交给编码器，缓冲不会无限增长。
录制报告记录采集帧数、提交帧数、补帧、错过的采集时隙和阶段耗时。真实画面刷新、文件帧率与调度误差是不同指标；0延迟和所有负载下完全不掉帧不能保证。
下载包不超过30 MB；完整编码器首次使用自动展开并校验，之后直接复用。解压目录和用户录像不计入下载包大小。

远程操作：播放器、区域选择和录屏控制条可在远程桌面中显示。Ctrl + Alt + P 暂停 / 继续，暂停时计时停止；Ctrl + Alt + R 开始 / 结束。绿色提示框位于选区外缘，不挡住选区内操作。默认开始录制后收起播放器；控制条排除屏幕捕捉，不会进入录像。

结束录屏时会显示保存阶段和进度。保存失败时保留待恢复文件，点击“查看待恢复文件”即可打开；可以再次录制。暂停后也可以直接点击“结束并回看”。

跨屏框选：可以从一个显示器拖到另一个显示器，按选区的实际像素录制。选区左下角显示暂停、结束、退出按钮；控制条不会被录入。结束后可回看片段，退出或关闭录屏面板会清除边框和控制条，正在录制时先保存。顶部文件名栏已移除，空白及品牌区域可拖动窗口。滚轮不再调音量，背景固定纯黑。打开视频时会同时预热 Windows 缩略图缓存。

0.6.13：修复快速暂停后结束短录像时末帧被声音时长截断的问题；准备阶段退出会取消启动。符合画面比例且设备支持时，4K放大使用显卡处理；过载仍可能重复帧，录制报告记录相关数量。
